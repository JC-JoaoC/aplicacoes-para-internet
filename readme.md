Aplicações para Internet
Data de entrega: até 06/05/2025
Tema: tecnologias para aplicações para internet

Criar uma aplicação web com três páginas:
• index.html
• conteudo.html
• contato.html
Utilize imagens, títulos, textos, listas, formulários etc.

Será avaliado:
• A utilização correta das tags HTML
• A endentação do código
• O layout

Observe: entregar em um arquivo .docx ou .pdf o print de cada uma das páginas
criadas, o código CSS e o código HTML de cada uma das páginas.
